# Arduino Projects

A collection of my Arduino projects while learning electronics, programming, and embedded systems.

## Projects

### 01 - LED Blink
My first Arduino project. Learned the basics of:
- Digital pins
- `pinMode()`
- `digitalWrite()`
- Delays

### 02 - Traffic Light
A simple traffic light simulation using:
- Arduino Uno
- Red, yellow, and green LEDs
- Resistors
- Breadboard

Concepts learned:
- Controlling multiple outputs
- Timing with `delay()`
- Using digital pins

## Tools Used

- Arduino IDE
- Wokwi Simulator
- Arduino Uno
